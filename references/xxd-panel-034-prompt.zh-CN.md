# XXD Panel 034｜多色橡皮章旅行田野注释生产提示词

只处理当前任务明确提供的这一张源照片。锁定主体或不可拆分关系、轮廓、比例、姿态、方向、空间距离、开口、重叠、叙事特征与颜色性格，至少保留三个源图专属线索。不要借用旧成品或其他输入的章印母题、油墨色组、注释、位置和纹理。

## 一枚小尺度、可识别的手刻橡皮章

删除无关细节。用剪影、2–4 个专色区域、粗细不均的刻线、负形切口和必要的少量叠压，把源图重构为一枚小或中小尺度橡皮章。缩略观看仍须保住源图方向、空间关系和视觉记忆点。禁止旅游纪念章、邮票、护照章、默认圆印、贴纸、Logo、卡通和完整场景复制。

根据源图方向、比例与视觉重心决定偏心、贴边或偶尔有依据的局部裁切。保留大面积主动留白，背景为暖白、浅燕麦、奶油色或其他与源图兼容的浅色纤维纸。一枚章印始终是主角，不散布许多同权重章印，也不填满画面。

## 专色油墨与真实盖印

从照片提取 2–4 种最有辨识度的颜色作为专色油墨，每种颜色承担明确结构区域、层次或点睛职责，用分色、叠印、明度和轻微套色错位建立深度。禁止固定旅行色卡，也不逐色翻译原照片。

呈现粗细不均的刻线、小凿痕、断墨、颗粒油墨、纸张透底、边缘缺口、压力变化和轻微套色错位。磨损必须沿雕刻与盖印结构发生，同时保住决定性轮廓。拒绝均匀数字做旧、平滑矢量、脏污复古滤镜、模糊复印噪声、厚重3D浮雕和儿童手工感。

## 田野注释

自动文案从可靠地点、主体、状态、动作或有依据的意象中提炼一个简短标题，只增加 2–3 个有依据的关键词或一句极短说明。`No.` 只在用户提供、可靠确认或明确作为本批次顺序号时出现；不得虚构历史编号、坐标、日期或来源。

使用小型打字机字体或档案式微排版，与章印边缘、基线、局部轮廓或主动留白对齐。文字是安静记录层，不是商业标题或旅游口号。用户准确文案逐字保留，并遵守目标文字体系的字形、方向、标点、空格与语义断行。无文字模式保持同一章印、油墨、盖印、尺度和纸张系统，但不生成文字或伪文字。

## 模式与验收

严格服从附加的 `OUTPUT MODE`、`FINAL SIZE` 与 `DESIGN FRAME`。双联模式只生成设计半幅；纯设计与壁纸不显示原照片。每张壁纸按设备重新构图，不裁切其他设备成果，不绘制系统 UI 或设备模型。连贯壁纸共同参考原照片与同一张已批准定调图，绝不串联衍生图。
